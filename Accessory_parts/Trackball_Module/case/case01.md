# 親指トラックボールケース 34mm ビルドガイド

## 必要部品

![case_list1](./imgs/ckw12_img1.jpg)

|No.| 名前 | 数 | 備考 |
|:--:| :-- | :--: | :-- |
| 1 | トラックボールケース（ボールケース） | 1個 | 3Dプリント製 |
| 2 | トラックボールケース（基板ホルダー） | 1個 | 3Dプリント製 |
| 3 | セラミックボール(2mm) | 3個 |  |
| 4 | ネジ類 | 2個 |  |

## 組み立ての手順

1. Trackball Moduleのはんだ付け
1. ケースにセラミックボールを固定する
1. ケースにTrackball Moduleを固定する
1. ケースを基板に固定する
1. 完成

## 1. Trackball Moduleのはんだ付け

Trackball Module のはんだ付けを行います。
詳しくは[Trackball Module ビルドガイド](../readme.md)を確認してください。

## 2. ケースにセラミックボールを固定する

トラックボールケース（ボールケース） に セラミックボール(2mm) を固定します。

ボールケース内部にはセラミックボールを固定する穴が3個所あるので、それぞれに押し込んでください。
![process02_01](./imgs)

## 3. ケースにTrackball Moduleを固定する

Trackball Module を トラックボールケース（基板ホルダー） に乗せて ボールケース に差し込み固定します。
![process03_01](./imgs)

## 4. ケースを基板に固定する

トラックボールケースをネジ止めし固定します。
![process03_01](./imgs)

## 5. 完成

![process04_01](./imgs)

以上で取りつけ完了です。
