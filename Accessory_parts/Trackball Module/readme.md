## 組み立ての前に

>[!CAUTION]
**実際の組み立てを始める前に、このビルドガイドを最後までお読みください。**

組み立てには先端の熱くなるはんだごてを使用します。作業を中断し席を離れる際などは電源を切るなどし、やけどや怪我には十分ご注意ください
道具の使い方は遊舎工房の読み物ページがございます。
詳細はこちらをご参照ください。
[自作キーボードのはんだ付け 基本編](https://shop.yushakobo.jp/pages/handaduke-kihon)

## 組み立ての手順

1. センサーの取り付け
1. フラットケーブルのはんだ付け（モジュール側）
1. フラットケーブルのはんだ付け（基板側）
1. 3Dプリントケース組み立て・固定

## 1. センサーの取り付け

PMW3360DM-T2QU を Trackball module基板 に取り付けし、はんだ付けします。

取り付け向きを間違えた場合、動作しなくなってしまうため、取り付け向きを確認の上取り付けてください。
![process01_01](./imgs)

![process01_02](./imgs)

## 2. フラットケーブルのはんだ付け（モジュール側）

AWG-26-2.54-6P（フラットケーブル）をはんだ付けします。

最初にフラットケーブルにマークを付けます。
※不要であれば飛ばしてしまって構いません。
![process02_01](./imgs)

次に、ケーブルの目印をあわせてフラットケーブルのはんだ付けを行います
ケーブルの端子を差し込んだ上で、6箇所のはんだ付けを行ってください。
![process02_02](./imgs)

## 3. フラットケーブルのはんだ付け（基板側）

フラットケーブルをキーボード側の基板に取り付けます。
はんだ付けはモジュール側の印と基板側の印が合うように取り付けてください。
![process03_01](./imgs)

非対応のキーボードに対応させる場合は、[Trackball module 開発者用ドキュメント](for_developers/readme.md)をご確認ください。

## 4. 3Dプリントケース組み立て・固定

別売りのケースにモジュールを取り付けます。
ケースによって組み立て方法は異なりますので、それぞれのビルドガイドを確認してください。
※順次追加される予定です。
[親指トラックボールケース 34mm](case/case01.md)
